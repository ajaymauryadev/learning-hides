# Per-Code-File Learning Notes

Important source/config file create hone par yahan matching flattened Markdown note
banega.

Example:

```text
Source: src/config/database.js
Note:   notes/each-code-file/src.config.database.js.md
```

Explanatory Markdown docs ko duplicate explanatory notes nahi chahiye. Generated
lockfile ko line-by-line duplicate nahi karna; purpose, generation and important
entries explain karne hain.

## Required note sections

1. Source path
2. File category
3. Responsibility
4. Why it exists / what happens without it
5. Current compact code
6. Line-by-line explanation
7. Important words/operators/syntax
8. Imports and exports
9. File relationships / callers
10. Execution order/time
11. Input and request/data flow
12. Output and success path
13. Failure/error paths
14. Security considerations
15. Common mistakes
16. Debugging approach
17. Verification commands and actual evidence
18. Interview questions with Hinglish and easy-English answers
19. Practice exercise
20. Answer-after-attempt section

Notes code ke saath same topic mein update honge, taaki stale explanation survive na
kare.
